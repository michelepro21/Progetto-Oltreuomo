# Progetto Oltreuomo — 1.9.0

Aggiornamento strutturale:
- XP configurabili per singola Task (`XP base` o `XP/min`)
- difficoltà rimossa dalle Task; resta la valutazione 1–3
- Progressi semplificati senza contatori specifici per categoria
- categorie dinamiche creabili e modificabili
- ogni categoria può contribuire o meno al livello Oltreuomo
- categorie non-Oltreuomo e relative Task usano l'accento `#a78bfa`
- migrazione compatibile con i dati della 1.8.5

Prima dell'aggiornamento su iPhone è consigliato esportare un backup dalla 1.8.5.
